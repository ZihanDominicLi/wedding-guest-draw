# 婚礼现场彩排清单

## 婚礼前 3–7 天

- 域名、HTTPS、管理员登录和手机流量访问均正常。
- 在后台设置举办城市；这会决定“远道宾客组”。
- 上传最终横版婚礼照片，分别检查 16:9 和超宽投影。
- 逐项核对分组规则优先级，点击预览后再应用。
- 配置全部奖品、允许参与组和中奖人数。
- 下载最终二维码，使用 iPhone 和 Android 各扫码一次。
- 创建 100 位演示宾客，完整走一遍登记、锁池、抽取、公布、撤销。
- 下载应急 CSV，确认中文可在 Excel 正常打开。
- 执行数据库备份，并把备份副本移出服务器。

## 婚礼当天开场前

- 服务器、投影电脑和主持电脑接入稳定网络并连接电源。
- 大屏打开 `/screen` 并进入全屏；主持台显示“大屏在线”。
- 后台关闭不需要的演示数据，再确认正式宾客数量和未分组异常数。
- 开启“正式抽奖模式”，执行一次新备份。
- 浏览器关闭自动翻译、网页缩放保持 100%，系统开启勿扰模式。
- 准备下载好的应急 CSV 和纸质奖品顺序表。

## 每轮抽奖

1. 选择奖品、参与主组和中奖人数。
2. 确认候选人数大于等于中奖人数。
3. 点击“锁定候选名单”，此后宾客修改不会改变该轮快照。
4. 确认大屏滚动后点击“开始抽取”。服务端先保存结果，大屏才展示。
5. 现场确认无误后点击“公布中奖结果”。
6. 宾客放弃时填写原因并撤销；该宾客之后可重新参与。

## 故障处理

- 大屏断线：刷新 `/screen`，系统会恢复同一已保存结果，不会重抽。
- 主持页超时：刷新并查看当前轮次，不要连续点击新建。
- 网络中断：使用应急 CSV 和已打印流程表；恢复网络后不要补录虚构结果。
- 数据库健康失败：停止抽奖，查看 `docker compose logs app db`，先恢复服务或备份。
- 必须跳过备份门槛时：填写具体原因，不使用“测试”等模糊字样。

## 结束后

- 完成最终备份与应急 CSV 导出。
- 保存审计记录和获奖名单。
- 限制服务器访问或关机，按隐私约定删除宾客数据。
